# 一、需求说明

## 1.1 需求背景

### 1.1.1 需求背景

现有「服务设备 → 流量池」包含预购流量池、共享流量池。

在**预购流量池**的基础上进行修改，得到本次新增的第三种类型「**月固定流量池**」，类似单卡套餐的 Monthly Fixed 类型。

除本文明确写出的差异外，其他规则均继承预购流量池。

池每个自然月有固定的池容量，并收取固定的池容量费用；池内卡不再收取月租和套餐费用，仅对当月有用量的卡收取池卡月费。

月固定流量池同时支持上传文件批量停机、批量复机。人工批量停机成功后，后续月初不自动复机。

**目标**：

- 支持创建、续订月固定流量池，并按自然月重置固定容量；
- 支持配置和结算池容量费用、池卡月费；
- 支持按文件批量停机、复机，并保留操作结果；
- 不改变预购流量池、共享流量池现有逻辑。

### 1.1.2 功能清单

| 功能           | 说明                                                     |
| -------------- | -------------------------------------------------------- |
| 新增流量池类型 | 流量池类型增加「月固定流量池」，主列表支持筛选和展示。   |
| 新增流量池     | 配置「每月固定容量」、「池容量费用」、「池卡月费」。     |
| 池卡页面       | 展示月固定池配置、单卡月费计费结果及待停机状态。         |
| 续订           | 配置下一合约周期的每月固定容量和池容量费用。             |
| 批量停机       | 上传 ICCID 文件，校验通过后次月 1 日 0 点生效。          |
| 批量复机       | 上传 ICCID 文件，校验通过后立即生效。                    |
| 月度容量       | 每月 1 日结转上月数据后，清空月度用量并恢复固定容量。    |
| 月度计费       | 收取池容量费用、有用量卡的池卡月费，以及超池、池外费用。 |
| 操作日志       | 记录停机、复机的批次结果和单卡失败原因。                 |

| 角色                                                        | 功能权限 | 数据权限 |
| ----------------------------------------------------------- | -------- | -------- |
| 万利管理员                                                  | 所有     | 所有     |
| <span style="white-space: nowrap;">客户 / 客户管理员</span> | 无       | 无       |

## 1.2 业务流程、状态与公共规则

### 1.2.1 业务流程

主流程：

新增月固定流量池 → 配置漫游、每月固定容量、池容量费用 → 卡片入池 → 累计当月用量 → 次月 1 日月结 → 重置「池内总量」为每月固定容量、清零「池内用量」、清零「当月超池用量」、重置「当月剩余用量」。

停复机流程：

- 批量停机：上传后立即逐卡校验；通过的卡进入待停机，次月 1 日 0 点执行；
- 批量复机：上传后立即逐卡校验；仅已停机成功的卡立即复机。已申请停机但尚未生效的卡复机失败，待停机任务不取消。

### 1.2.2 状态流转



| 当前情况                                                     | 触发                                                         | 结果                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `active`                                                     | 批量停机校验通过                                             | 当月卡片保持当前状态，次月 1 日 0 点执行；操作日志记录本次停机及生效时间。 |
| 待停机                                                       | <span style="white-space: nowrap;">次月 1 日 0 点执行成功</span> | 状态改为 `suspend`，来源记为「人工批量停机」。               |
| 已申请停机但尚未生效                                         | 批量复机                                                     | 复机失败。卡片尚未停机成功，待停机任务不取消，仍于原生效时间执行。 |
| <span style="white-space: nowrap;">人工批量停机产生的 `suspend`</span> | 批量复机成功                                                 | 立即恢复为 `active`。                                        |
| 人工批量停机产生的 `suspend`                                 | 到达后续月初                                                 | 保持 `suspend`，不自动复机。                                 |

### 1.2.3 规则

每月 1 日 0 点，在上月用量和费用完成结转后：

1. 容量周期切换为新自然月；
2. 池内总量恢复为当前生效的每月固定容量；
3. 池内用量、超池用量、池外用量清零；
4. 剩余池内用量恢复为每月固定容量。

容量重置不改变合约周期，也不新增流量池周期记录。

**计费**

预购流量池对产生用量的卡片收取月租和套餐费用。月固定流量池不再收取这两项费用，改为按池卡月费收取。

| 费用项             | 预购流量池           | 月固定流量池                                     |
| ------------------ | -------------------- | ------------------------------------------------ |
| 有用量卡的月租     | 收取                 | 不收取                                           |
| 有用量卡的套餐费用 | 收取                 | 不收取                                           |
| 池卡月费           | 不收取               | 当月累计用量大于 0 的卡，每卡收取一次            |
| 池容量费用         | 不收取               | 每月按当前生效配置收取一次，与卡数和实际用量无关 |
| 超池费用           | 按预购流量池规则收取 | 沿用预购流量池                                   |
| 池外费用           | 按预购流量池规则收取 | 沿用预购流量池                                   |

池卡月费的累计用量包含池内用量和池外用量。同一 ICCID 同一账期只收取一次，月中入池、停机、复机不按天折算。待出池卡当月仍按本池结算，次月正式出池后不再计入。

`账单金额 = 池容量费用 + 有用量卡数 × 池卡月费 + 超池费用 + 池外费用`

容量和池容量费用分别配置，系统不按容量自动换算费用。本需求不做按天折算。

以下能力沿用平台现有流量池页面，本次不单独改造：

| 能力             | 复用说明                                             |
| ---------------- | ---------------------------------------------------- |

| 关闭、返回       | 池卡页面关闭后返回流量池主列表。                     |
